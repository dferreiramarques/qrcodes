# Gerador de QR Code

Gera um QR Code a partir de um URL, no próprio browser, e descarrega-o como imagem PNG.

Online: [qrcodes.monco.io](https://qrcodes.monco.io)

## Usar

Escreve o URL, carrega em **Gerar QR Code** e depois em **Download**. O URL não sai do teu browser.

Usa a biblioteca [qrcodejs](https://github.com/davidshimjs/qrcodejs) (MIT).
